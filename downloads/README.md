# E.D.N. — модель с прозрачным фоном

Готовые файлы после удаления фона из предоставленного видео. Сохранены 121 кадр, исходное разрешение 1216 × 1792 и частота 24 кадра/с; длительность — 5,04 секунды. Контур сглажен, цветная кайма уменьшена. Исходное движение сохранено.

## Скачать

- [Видео WebM с прозрачностью](edn-girl-transparent.webm?raw=true) — 3,3 МБ.
- [PNG-обложка](edn-girl-poster.png?raw=true) — 0,8 МБ.
- [Комплект для сайта](edn-transparent-video.zip?raw=true) — 11,3 МБ: WebM, MP4 с маской прозрачности, проигрыватель, анимированный WebP, обложка, страница просмотра и инструкция.

На странице файла в GitHub используйте **Download raw file**. Можно также скачать всю ветку через **Code → Download ZIP**.

## Использование

WebM поддерживает прозрачность при прямой вставке в Chrome и Firefox. В комплекте есть вариант MP4 + WebGL для браузеров с H.264 и WebGL. Safari отдельно в среде обработки не проверялся.

```html
<video autoplay muted loop playsinline
  poster="edn-girl-poster.png"
  style="width:min(100%,480px);height:auto">
  <source src="edn-girl-transparent.webm" type="video/webm">
</video>
```

Для публикации загрузите видео на свой сайт. Прямые ссылки GitHub предназначены для передачи файлов.

Прозрачность проверена декодированием всех 121 кадров и воспроизведением в Chromium. Мелкие детали волос ограничены качеством исходного сжатого ролика.
